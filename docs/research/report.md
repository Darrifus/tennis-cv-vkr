# ЛР 2 — обоснование актуальности ВКР

**Тема ВКР:** Разработка системы компьютерного зрения для анализа техники и параметров теннисных ударов

**Автор или участники команды:** Усольцева Дарья Дмитриевна

## 1. Кто занимается темой

### Исследователи и разработчики

| Имя | Связь с темой, работы или проекты | Ссылка |
|---|---|---|
| Yu-Chuan Huang | Модель для отслеживания маленького быстродвижущегося мяча на видео. Модель анализирует последовательность кадров и формирует тепловую карту положения мяча. Подход можно использовать как основу модуля трекинга мяча | [TrackNet](https://arxiv.org/abs/1907.03698) |
| Vito Reno | Ведущий автор работы по обнаружению теннисного мяча с помощью сверточной нейронной сети. Исследование рассматривает проблемы изменения освещения, размытия и малого размера мяча на видеозаписи. | [Convolutional Neural Networks Based Ball Detection in Tennis Games](https://openaccess.thecvf.com/content_cvpr_2018_workshops/w34/html/Reno_Convolutional_Neural_Networks_CVPR_2018_paper.html) |
| Arjun Raj | Ведущий автор TrackNetV4 — развития семейства TrackNet с картами внимания к движению. Метод предназначен для отслеживания быстрых спортивных объектов при размытии, частичном перекрытии и плохой видимости. | [TrackNetV4](https://github.com/TrackNetV4/TrackNetV4) |
| Zhiyuan Wang | Ведущий автор системы TAGS для анализа теннисных движений. Система использует трехмерные ключевые точки тела игрока и формирует оценку техники и рекомендации. Работа полезна для возможного развития проекта в сторону анализа движений игрока. | [Tennis Action Guidance System](https://openaccess.thecvf.com/content/ICCV2025W/AMFG/html/Wang_Generating_Tennis_Action_Instruction_Based_on_a_Large_Language_Model_ICCVW_2025_paper.html) |

Эти направления непосредственно связаны с обнаружением игрока, ракетки и теннисного мяча. | [GraphiCon](https://www.graphicon.org/conference) |
